## 引言

前两课解决了线性规划的求解问题。第十一课用 MATLAB 和 LINGO 得到同一组答案，第十二课把几类看似不属于线性规划的问题改写成标准形。求解只走到一半，建模真正要回答的问题在解出来之后才出现。

生产现场不会长期沿用一张固定的排产表。原料供应有小幅波动，单价随行就市，工艺改版会动到耗料定额，市场上还可能冒出可替代的新产品。这些变化的幅度有限，却直接决定原方案是否继续适用。灵敏度分析要做的，是把这种不确定性折算成能写进报告的数字：哪些参数可以随便动，动到哪条界限方案开始失效，失效之后目标值退到什么程度。

本课沿用第十一课的生产计划题，参数完全一致，便于对照：

$$
\max \quad Z = 50x_1 + 40x_2
$$

$$
\text{s.t.} \quad 2x_1 + x_2 \leq 60, \quad 2x_1 + 4x_2 \leq 120, \quad x_1, x_2 \geq 0
$$

最优解为甲产品 20 件、乙产品 20 件，利润 1800 元。以往要判断这个方案稳不稳，只能逐个拨动参数、重新求解、记录结果，工作量随参数个数线性增长。自 **R2026a** 起，`linprog` 增加了第六个返回值 `sensitivity`，一次求解就能取到完整的灵敏度信息：各参数的可变区间、区间端点的目标值、区间内单位变动带来的目标值增量。



## 新版本给的方法：第六个返回值 sensitivity

`linprog` 求解的线性规划问题写成：
$$
\min_{x} \; f^T x \quad \text{such that}
\begin{cases}
\mathrm{bl} \le A \cdot x \le b \\
\mathrm{Aeq} \cdot x = \mathrm{beq} \\
\mathrm{lb} \le x \le \mathrm{ub}.
\end{cases}
$$
在第六个输出位置接收这个返回值：

```matlab
[x,fval,exitflag,output,lambda,sensitivity] = ...
    linprog(f,A,b,Aeq,beq,lb,ub);
sensitivity
```

返回值是一个 `SensitivityAnalysis` 对象，不是数值向量。对象内部按变量与约束分成两组属性，每组各含若干张表：

```text
sensitivity =
  SensitivityAnalysis with properties:

    变量灵敏度:
       ObjectiveCoefficient: [Nx5 table]
       LowerBound: [Nx5 table]
       UpperBound: [Nx5 table]

    约束灵敏度:
       InequalityLHS: [NIneqx5 table]
       InequalityRHS: [NIneqx5 table]
       EqualityRHS: [Neqx5 table]
```

| 表名 | 描述 |
|---|---|
| ObjectiveCoefficient | 目标函数系数 f 的灵敏度 |
| UpperBound | 上界 ub 的灵敏度 |
| LowerBound | 下界 lb 的灵敏度 |
| InequalityLHS |线性不等式约束 bl 的灵敏度  |
| InequalityRHS | 线性不等式约束 b 的灵敏度 |
| EqualityRHS | 线性等式约束 beq 的灵敏度 |

### 每张表都是同一个五列结构

六张表的行数按变量个数或约束条数而定，列结构都是同样的五列：

| 列名 | 描述 |
|---|---|
| LowerLimit | 模型参数在不改变当前最优基的情况下所能取的最小值 |
| UpperLimit | 模型参数在不改变当前最优基的情况下所能取的最大值 |
| ObjectiveValueAtLowerLimit | 如果将模型参数更改为 LowerLimit，则在最优解处的目标函数值为 |
| ObjectiveValueAtUpperLimit | 如果将模型参数更改为 UpperLimit，则在最优解处的目标函数值为 |
| ObjectiveValueChangeRate | 目标函数值对模型参数在区间 (LowerLimit, UpperLimit) 内的变化率 |

这五列回答三个层次的问题，而且都在同一次求解里给出：

- 可动范围：`LowerLimit` 与 `UpperLimit` 最优基不变的区间；
- 边界代价：两个 `ObjectiveValueAt*` 端点处的目标函数的值；
- 区间内斜率：`ObjectiveValueChangeRate` 给出区间内的变化率。


## 六类参数含义

在第十一课的生产计划题上运行，取 sensitivity 的全部内容：

```matlab
f = [-50, -40];              % 最大化取负，转成最小化
A = [2, 1;                  % 原料 A 的消耗
     2, 4];                 % 原料 B 的消耗
b = [60; 120];               % 两种原料的日供应上限
lb = [0; 0];                 % 非负约束
ub = [];                     % 无上界

[x, fval, exitflag, output,lamnbd,sensitivity] = linprog(f, A, b, [], [], lb, ub);
```

### 目标函数系数 f 的灵敏度：单价的变化范围

```matlab
sensitivity.ObjectiveCoefficient

ans =

  2x5 table

    LowerLimit    UpperLimit    ObjectiveValueAtLowerLimit    ObjectiveValueAtUpperLimit    ObjectiveValueChangeRate
    __________    __________    __________________________    __________________________    ________________________

           -80           -20                         -2400                         -1200                          20
          -100           -25                         -3000                         -1500                          20
```
表中每一行对应一个变量。本问的目标函数是 $f  = c_1x_1 + c_2x_2= 50x_1 + 40x_2$，只有两个变量，所以共两行。表中出现负号，是因为原问题求最大值，而 MATLAB 的 `linprog` 求最小值，代入时要先把系数取负。

这张表说明：对目标函数 $f = c_1 x_1 + c_2 x_2$，单价 c1 在 80 到 20 之间变动（原值 50，c2 不动）、c2 在 100 到 25 之间变动（原值 40，c1 不动）时，最优解都不变。两个区间的写法与表里一致，左端是 LowerLimit，右端是 UpperLimit。

ObjectiveValueAtLowerLimit 给的是区间左端的目标值：只把 c1 改成 80、c2 不动，最优解处的目标值为 2400；只把 c2 改成 100、c1 不动，目标值为 3000。

ObjectiveValueAtUpperLimit 给的是区间右端的目标值：只把 c1 改成 20、c2 不动，目标值为 1200；只把 c2 改成 25、c1 不动，目标值为 1500。

ObjectiveValueChangeRate 是区间内的变化率：c1 每增加一个单位（c2 不动），目标值增加 20；c2 每增加一个单位（c1 不动），目标值同样增加 20。这两行数值相同，是因为两个产品当时各产 20 件，每件贡献的利润恰好都是 20。

### 验证ObjectiveValueChangeRate
把第十一课的目标函数改为
$$
\max \quad Z = 60x_1 + 40x_2
$$

$$
\text{s.t.} \quad 2x_1 + x_2 \leq 60, \quad 2x_1 + 4x_2 \leq 120, \quad x_1, x_2 \geq 0
$$

修改后的 $c_1 = 60$ 仍落在表给的两个端点之间，所以最优解不变。c1 从 50 涨到 60，增加了 10 个单位，按变化率折算，目标值应从 1800 变到 $f = 1800 + 20 \times 10 = 2000$。

用代码核对：
```matlab
f = [-60, -26];              % 最大化取负，转成最小化
A = [2, 1;                  % 原料 A 的消耗
     2, 4];                 % 原料 B 的消耗
b = [60; 120];               % 两种原料的日供应上限
lb = [0; 0];                 % 非负约束
ub = [];                     % 无上界
[x, fval, exitflag, output,lamnbd,sensitivity] = linprog(f, A, b, [], [], lb, ub);
x
fval
```
输出为：
```matlab
x =

    20
    20


fval =

       -2000 
```
去掉负号，与预测的 2000 一致。

### 约束右端项 b 的灵敏度：原料还能加多少

`InequalityRHS` 的两行对应两条资源约束的右端项，第 1 行为 b1，第 2 行为 b2。本题的实际运行结果为：

```matlab
sensitivity.InequalityRHS

ans =

  2x5 table

    LowerLimit    UpperLimit    ObjectiveValueAtLowerLimit    ObjectiveValueAtUpperLimit    ObjectiveValueChangeRate
    __________    __________    __________________________    __________________________    ________________________

            30           120                          1200                          3000                          20
            60           240                          1500                          2400                           5
```

表中每一行对应一条约束的右端项，本题两条不等式约束，所以两行。第 1 行是原料 A 的日供应上限，第 2 行是原料 B 的日供应上限。

这张表说明：原料 A 的日供应量在 30 到 120 之间变动（原值 60）、原料 B 在 60 到 240 之间变动（原值 120）时，最优基不变，最优解仍落在两条资源约束的交点上。

ObjectiveValueAtLowerLimit 是区间左端的目标值。b1 压到 30、b2 仍为 120 时，目标值为 1200。这个数可以手算，约束条件变成

$$
2x_1 + x_2 \le 30, \qquad 2x_1 + 4x_2 \le 120, \qquad x_1, x_2 \ge 0
$$

可行域的顶点有两类来源：两条边界线的交点，以及边界线与坐标轴的交点。逐一定出来：

- 两条线相交：由 $2x_1 + x_2 = 30$ 得 $x_2 = 30 - 2x_1$，代入 $2x_1 + 4x_2 = 120$，得 $120 - 6x_1 = 120$，$x_1 = 0$，回代 $x_2 = 30$，交点为 $(0,30)$；
- 与 $x_1$ 轴的交点：$x_2 = 0$ 时，$2x_1 \le 30$ 给 $x_1 \le 15$，$2x_1 \le 120$ 给 $x_1 \le 60$，取小得 $(15,0)$；
- 与 $x_2$ 轴的交点：$x_1 = 0$ 时，$x_2 \le 30$ 与 $4x_2 \le 120$ 即 $x_2 \le 30$，得 $(0,30)$；
- 原点 $(0,0)$。

把顶点代入目标函数：

$$
Z(0,0) = 0, \quad Z(15,0) = 750, \quad Z(0,30) = 1200
$$

最大值 1200 落在 $(0,30)$，与表里的 ObjectiveValueAtLowerLimit 一致。$x_1 = 0$ 就是甲产品退出。原料 A 只剩 30 吨，按甲的耗料每件 2 吨只能做 15 件，按乙的耗料每件 1 吨能做 30 件。乙每吨 A 换回 40 元，甲每吨 A 只换回 25 元，资源一紧，单位资源收益低的甲先出局。

b2 压到 60、b1 仍为 60 时，目标值为 1500，约束条件变成

$$
2x_1 + x_2 \le 60, \qquad 2x_1 + 4x_2 \le 60, \qquad x_1, x_2 \ge 0
$$

两线交点由 $x_2 = 60 - 2x_1$ 代入 $2x_1 + 4x_2 = 60$，得 $60 - 6x_1 = 0$，$x_1 = 10$，$x_2 = 40$。这个点要回到原约束检验：$2 \times 10 + 40 = 60$ 卡在第一条线上，但 $2 \times 10 + 4 \times 40 = 180 > 60$，越过了第二条，所以不可行。可行顶点只剩 $(0,0)$、$(30,0)$、$(0,15)$，其中 $(30,0)$ 是第一条约束与 $x_1$ 轴的截点，$(0,15)$ 是第二条约束与 $x_2$ 轴的截点。三点代入目标函数分别为 $0$、$1500$、$600$，最大值 1500 落在 $(30,0)$，乙产品退出。

两处换位原因相同：A 与 B 的相对稀缺程度变了，贴着最紧那条约束的顶点成为新最优解。所谓最优解移动，指的就是顶点在这些交点之间换位。


ObjectiveValueAtUpperLimit 是区间右端的目标值。b1 放到 120、b2 不动时目标值为 3000，最优点移动到 (60,0)，原料 A 的约束线与 x 轴正好交于此；b2 放到 240、b1 不动时目标值为 2400，最优点在 (0,60)。

ObjectiveValueChangeRate 是区间内的变化率，也就是影子价格：b1 每增加 1 吨（b2 不动），利润增加 20 元；b2 每增加 1 吨（b1 不动），利润增加 5 元。

两种原料在原方案里都已用满，影子价格却差了四倍。差别来自耗料结构：甲产品每件吃 2 吨 A、2 吨 B，乙产品每件吃 1 吨 A、4 吨 B。多一吨 A 能换来的额外利润更高，是因为它卡着单位利润更高的甲产品。

区间的经营含义同样清楚：b1 在 30 至 120 吨之间时影子价格恒为 20 元每吨；越过 120 吨，起作用的约束换成原料 B，再增加 A 不带来利润。这一点在 ObjectiveValueAtUpperLimit 上看得见：b1 取 120 时目标值 3000，b2 取 240 时是 2400，对应的顶点分别是 (60,0) 与 (0,60)。

### 验证 ObjectiveValueChangeRate

把第十一课的原料 A 日供应上限从 60 吨提到 61 吨，其余参数不动：

$$
\max \quad Z = 50x_1 + 40x_2
$$

$$
\text{s.t.} \quad 2x_1 + x_2 \leq 61, \quad 2x_1 + 4x_2 \leq 120, \quad x_1, x_2 \geq 0
$$

修改后的 b1 = 61 落在区间 [30, 120] 内，最优基不变。相比原来的 60 多了 1 个单位，按变化率折算，目标函数应为 Z = 1800 + 20 × 1 = 1820。

用代码核对：

```matlab
f = [-50, -40];              % 最大化取负，转成最小化
A = [2, 1;                  % 原料 A 的消耗
     2, 4];                 % 原料 B 的消耗
b = [61; 120];               % 原料 A 提到 61 吨
lb = [0; 0];                 % 非负约束
ub = [];                     % 无上界
[x, fval] = linprog(f, A, b, [], [], lb, ub);
x
fval
```

输出为：

```matlab
x =

    20.6667
    19.6667

fval =

       -1820
```

去掉负号，与预测的 1820 一致。此时甲、乙两种产品同时在产，最优解随 b1 连续移动。这也是「最优基不变」的实际含义：顶点位置动了，撑住它的两条约束没动。

### 约束左端系数 A 的灵敏度：工艺定额动得起吗

`InequalityLHS` 的两行对应两条约束左端的系数，本题的实际运行结果为：

```matlab
sensitivity.InequalityLHS

ans =

  2x5 table

    LowerLimit    UpperLimit    ObjectiveValueAtLowerLimit    ObjectiveValueAtUpperLimit    ObjectiveValueChangeRate
    __________    __________    __________________________    __________________________    ________________________

          -Inf            60                         -1800                         -1800                           0
          -Inf           120                         -1800                         -1800                           0
```

两行对应两个产品的耗料定额，第 1 行是甲产品的单位耗料，第 2 行是乙产品的单位耗料，原值分别是 2 与 4。两行的上限分别是 60 与 120，即这两个系数各自能移到的最远处。变化率整列为 0，是这张表最要紧的一处。

0 就是结论：在 b = (60,120) 这组右端项下，把耗料定额推向区间任意一端，最优方案都不变，利润也不随之增减。表中 ObjectiveValueAtLowerLimit 与 ObjectiveValueAtUpperLimit 都是 -1800，两个端点给出同一个目标值，正是这个意思。

LowerLimit 为 -Inf，表示这个方向没有界限：耗料定额往下调只会让约束更松，只要生产还有利可图，方案就不会被卡住。有内容的是 UpperLimit 那一列：甲产品的单位耗料从 2 拉到 60、乙产品的从 4 拉到 120 之前，当前方案一直站得住；越过这条上限，该约束就移到当前最优顶点的另一侧，方案随之整体改变。

这张表的读法与前三类不同。目标系数和右端项变动时，解在原有顶点附近连续移动，变化率是稳定的常数，可以直接讲「每吨涨多少钱」。左端系数一动，两条直线的交点本身就在动，约束之间的紧松关系可能中途切换。所以这里的 0 要读作「在当前基下没有边际收益」，不能读作「怎么改都一样」。真要调整工艺定额，应当按多参数变动重新求解，不宜把这张表当成线性公式来套。

由此得出一条使用限制：`sensitivity` 给出的区间都以单参数变动、其余参数固定为前提。工艺定额的调整往往牵动整条产线的数据，这时不宜直接引用单个系数的区间，应按多参数变动重新评估。

### 变量下界 lb 的灵敏度：界起没起作用

`LowerBound` 的两行对应两个变量的下界，本题的实际运行结果为：

```matlab
sensitivity.LowerBound

ans =

  2x5 table

    LowerLimit    UpperLimit    ObjectiveValueAtLowerLimit    ObjectiveValueAtUpperLimit    ObjectiveValueChangeRate
    __________    __________    __________________________    __________________________    ________________________

          -Inf            20                           Inf                          1800                           0
          -Inf            20                           Inf                          1800                           0
```

表中每一行对应一个变量的下界，第 1 行是 x1，第 2 行是 x2。两行的 ObjectiveValueChangeRate 都是 0，UpperLimit 都是 20。

0 就是结论：最优解在 (20,20)，离下界 0 还远，两条下界没有参与定格方案。变化率为 0，表示放宽或收紧该界都不改变利润。

LowerLimit 为 -Inf、ObjectiveValueAtLowerLimit 为 Inf，两处都在说同一个事实：这个方向没有界限。下界往下调多少都碰不到解，因为解根本不在下界上。

UpperLimit 为 20，是这张表里唯一有实际含义的数字：下界一旦抬到 20，该变量就被顶到界上，最优解被迫改变。

### 变量上界 ub 的灵敏度：产能还没卡住

`UpperBound` 的两行对应两个变量的上界。本题在 `ub = []` 下求解，变量没有上界，结果如下：

```matlab
sensitivity.UpperBound

ans =

  2x5 table

    LowerLimit    UpperLimit    ObjectiveValueAtLowerLimit    ObjectiveValueAtUpperLimit    ObjectiveValueChangeRate
    __________    __________    __________________________    __________________________    ________________________

            20           Inf                          1800                           Inf                           0
            20           Inf                          1800                           Inf                           0
```

表中每一行对应一个变量的上界，第 1 行是 x1，第 2 行是 x2。两行变化率都是 0，LowerLimit 都是 20。

给一个产能上限就能看出这张表的用处。比如把甲产品限制在每日 15 件，上限落在 20 以下，最优解被顶到界上，该行变化率变成非零值，含义是每放宽一件产能能多赚多少。本题没有设上限，上界表给不出这类信息。

两张界约束表都先看变化率，为 0 就跳过。

### 等式右端 beq 的灵敏度：本题是空表

`EqualityRHS` 对应 `Aeq*x = beq` 中的右端项。本题两条约束都是不等式，没有等式约束，结果是一张空表：

```matlab
sensitivity.EqualityRHS

ans =

  0×5 empty table
```

零行，五列的表头结构还在，表内没有数据。空表不代表求解失败，只说明模型里没有这类参数。

想让这张表出现内容，可以把原料 B 的约束改写成等式 `2x1 + 4x2 = 120` 再求解。此时原料 B 必须恰好用完，`EqualityRHS` 多出一行，`InequalityRHS` 少掉一行。同一条约束，写成不等式就进右端项表，写成等式就进等式右端表，数值不变。可见六张表的分法依据是参数的书写形式，不是物理含义。

## 一个完整的读表流程

把上面的要点收成一套流程，写论文时可以直接照着走：

1. **确认解的合法性**：检查 `exitflag` 是否为 1，`output.constrviolation` 是否为 0。解不合法时，灵敏度结论没有意义。
2. **定位当前基**：确认最优解中哪几条约束取等号、哪些变量取非零值。这组约束是方案的支撑结构，后续结论都以它为参照。
3. **读目标系数表**：区间给出单价的可动范围，变化率等于对应产量，可作复核。
4. **读右端项表**：变化率即影子价格，区间给出资源可增加的空间以及约束切换的临界点。
5. **依次检查其余各表**：左端系数、上下界、等式右端。空表跳过，变化率为 0 者说明该类参数未参与方案的确定。
6. **结论区分解与值**：区间保护的是方案，而非利润。

六张表按这个顺序读下来，各条结论之间能互相印证。


## 结语

本课没有引入新算法，`linprog` 还是同一个 `linprog`。变的是提问方式：从「最优解是多少」转到「最优解有多稳」。

竞赛评审看的从来不只是 1800 这个数。能说清 1800 在什么条件下成立、什么时候失效、失效后又是什么结果，才算读懂了模型。这一步不需要额外工具，在 `linprog` 里多接一个 `sensitivity` 输出就够。

线性规划这一组课到这里告一段落。从建模、求解、改写成标准形，到解出来之后评估稳定性，这条线覆盖了竞赛里线性规划题的主要环节。
