## 引言

前四课解决的是同一类问题：目标函数线性、约束线性、变量连续。一旦有一条不满足，`linprog` 与 LINGO 会报错，或返回错误的解。

然而建模时，题目很少以标准形式出现：成本中可能出现绝对值，指标可能要求「使最坏情形的指标最小」，价格可能按销量分段递减。这些形式都超出了线性规划的直接表述范围。

这一课只做一件事：把这几类题目改写成线性规划，从而沿用已有的求解器，不必另学算法。改写的手法只有一个：**引入新变量**，把不能直接送入求解器的部分替换成线性形式。

改写成立的前提是题目本身具备相应结构：变量之间为线性关系，非线性只出现在有限位置。若题目确实非线性，例如目标函数含两个决策变量的乘积，则本节方法不适用，需要非线性规划。

改写是否成立，必须通过代回原题验证：把改写后的最优解代入原始表达式，检查目标值是否一致、约束是否全部满足。例如目标函数中的绝对值若可直接拆成两条不等式，说明非线性仅来自「取绝对值」这一层，底层仍是线性的；若不能拆开，代回后必然出现不一致。

## 含绝对值的目标函数

先看最简单的一类问题：某车间的三个工位分别需要 6、10、7 名工人，临时工只能按同一数量配到每个工位。配多则浪费，配少则缺人，求使总缺口与总富余之和最小的配置数量 x。

这里的绝对值是**一个数减去一个常数**：

$$ \min \quad f(x) = |x - 6| + |x - 10| + |x - 7| $$

绝对值不是线性函数，无法直接交给求解器。改写的办法是：令

$$ u_i = |x - a_i| $$

于是对每个 i 同时成立两条不等式：

$$ x - a_i \leq u_i, \qquad a_i - x \leq u_i $$

再加一条非负约束 `u_i ≥ 0`。原问题等价于：

$$ \min \quad \sum_{i=1}^{3} u_i \quad \text{s.t.} \quad x - a_i \leq u_i, \quad a_i - x \leq u_i, \quad u_i \geq 0 $$

**为何等价？** 关键在于目标函数求最小。求解器会尽量把每个 uᵢ 压小，而两条约束合起来要求 `u_i ≥ |x - a_i|`，于是 uᵢ 最终只能停在它的下界 `|x - a_i|` 上。若目标改为求最大，uᵢ 会被推向无穷，改写不成立——**该技巧只对最小化问题有效**，这是第一个必要条件。

写成 MATLAB 代码：

```matlab
% min f = |x - 6| + |x - 10| + |x - 7|
a = [6; 10; 7];

% 变量向量 [x; u1; u2; u3]
f = [0; 1; 1; 1];

% 约束 1: x - u_i <= a_i    约束 2: -x - u_i <= -a_i
A = [ 1, -1,  0,  0;                                         % x - u1 <= 6
      1,  0, -1,  0;                                         % x - u2 <= 10
      1,  0,  0, -1;                                         % x - u3 <= 7
     -1, -1,  0,  0;                                         % -x - u1 <= -6
     -1,  0, -1,  0;                                         % -x - u2 <= -10
     -1,  0,  0, -1];                                        % -x - u3 <= -7
b = [6; 10; 7; -6; -10; -7];

lb = [-Inf; 0; 0; 0];　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　% x 无下界，u_i >= 0
ub = [];

[x, fval, exitflag] = linprog(f, A, b, [], [], lb, ub);

fprintf('x = %.4f\n', x(1));
fprintf('f = %.4f\n', fval);
fprintf('三项绝对值为 %.4f、%.4f、%.4f\n', x(2), x(3), x(4));
```

最优解为 `x = 7`，三项绝对值分别为 1、3、0，总和为 4。三个数排序后 7 位于中间，与「到各点距离之和最小取中位数」的结论一致。求解器并不依赖该结论，只是把 uᵢ 压到了下界。

这套改写也说明了 uᵢ 为何必须加非负约束：若 uᵢ 允许取负，约束 `x - a ≤ u` 与 `a - x ≤ u` 可被一个负数同时满足，此时 u 不再等于绝对值的上界，而是无意义的量。非负约束把 uᵢ 限制在下界之上，才能保证它最终落在绝对值上。

## 含绝对值的约束

同一类改写也适用于绝对值出现在约束中的情形，但成立条件更严格。

设某产品对温度的偏差有要求，实际温度 x 与设定值 a 的偏差不得超过 d：

$$ |x - a| \leq d $$

这可以直接拆成两条普通不等式，无需引入新变量：

$$ x - a \leq d, \qquad a - x \leq d $$

即 `-d ≤ x - a ≤ d`。**绝对值在约束中且要求「不超过」时可直接拆开；只有当绝对值出现在目标函数中，或约束要求「不小于某数」时，才需要引入 uᵢ 并依赖最小化方向。**

同样是绝对值，位置不同，改写的成立条件也不同。以下两种情形不能沿用上一节的方法：

- 约束形如 `|x - a| ≥ d`（要求偏差至少为 d），可行域为其两侧的不连通区域，不是凸集，线性规划无法表达，属于整数规划范围，本课不展开；
- 目标函数为 `max |x - a|`，需要的是上界的最大值而非最小值，uᵢ 会被推向无穷，同样不成立。

两类的失败形式不同：第一类属于可行域形状问题，直接使用 `linprog` 会返回「无可行解」，或给出落在不可行区间的伪解；第二类属于无界问题，求解器返回的状态码明确指向「无界」。遇到这两种返回，应先检查绝对值的位置与方向，而非调整参数。

## 最小化最大值

第二类常见表述是把「所有指标均需达标」改为「使最差指标尽可能好」：

$$ \min \quad \max_{i} \quad c_i^{T}x $$

这类问题有明确的工程含义：流水线的节拍由最慢的工序决定，缩短该工序即可加快整线。数学上，把最大值作为待求量：

$$ \min \quad z \quad \text{s.t.} \quad c_i^{T}x \leq z, \quad i = 1,2,\cdots,m $$

新变量 z 是所有指标的公共上界。求解器压缩 z 时会同时压低各 `c_i^T x`，最终 z 停在无法再降的最大值上，恰好等于原来的 max。该改写同样要求原问题求最小；若原问题为 `max min`，则应令 z 为公共下界并求最大。

### 例一：调节参数压低负荷峰值

某设备在三段时间内的负荷为 `4y`、`6y - 5`、`8 - 2y`（y 为调节参数），要求负荷峰值最低。按定义，这道题就是让三段负荷里最大的那个尽量小：

$$ \min_{y} \quad \max \left\{ 4y, \; 6y - 5, \; 8 - 2y \right\} $$

这就是一道 min-max 问题。该形式不能直接送入求解器：目标是「先取最大、再取最小」的复合运算，不是 x 的线性函数，也不光滑。求解器只接受 `c^T x` 形式的线性目标，因此需要改写。

关键在于**用变量表示最大值**。峰值本身是一个具体的数，记为 z；z 若要等于峰值，必须不小于每一段负荷：

$$ z \geq 4y, \quad z \geq 6y - 5, \quad z \geq 8 - 2y $$

这三条约束只保证 z 是一个上界，单凭它们 z 可以任意大。因此目标改为**最小化这个上界**——只要目标是最小化，求解器就会不断压低 z，直到再压就会违反上述某条约束为止。此时 z 恰好等于三段负荷中的最大值，与原式的 max 一致：

$$ \min \quad z \quad \text{s.t.} \quad 4y \leq z, \quad 6y - 5 \leq z, \quad 8 - 2y \leq z $$

这就是新增 z 的全部理由：**目标中不能出现 max，就用一个变量承载最大值，再对该变量求最小**。z 不是预先设定的参数，也不需要事先估计，由求解器在求解过程中确定。

```matlab
% min z
% s.t. 4y - z <= 0,  6y - z <= 5,  -2y - z <= -8
f = [0; 1];　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　% 变量 [y; z]，目标是 z

A = [ 4, -1;                                                 % 4y <= z
      6, -1;                                                 % 6y <= z + 5
     -2, -1];                                                % 8 - 2y <= z
b = [0; 5; -8];

lb = [-Inf; -Inf];

[y, fval] = linprog(f, A, b, [], [], lb, []);
fprintf('y = %.4f, 峰值 z = %.4f\n', y(1), fval);
```

结果为 `y = 1.3333`、`z = 5.3333`：三段负荷分别为 5.3333、3、5.3333，峰值被压到 5.3333，且两段负荷同时达到该值。两段同时取到峰值并非巧合：若峰值仍可下降，说明它只由某一段决定；两段同时达到峰值，意味着再降低任何一点都会有另一段超过该值，这正是最优的标志。

这里需注意 `8 - 2y ≤ z` 必须先整理为 `-2y - z ≤ -8`，负号与常数项都要随移项改变，这是第二类问题最常见的对错分界点。

### 例二：三条产线分摊订单，压低最贵那条

第二个例子是另一种最大值问题：三条产线共同承担 1000 件订单，单位成本分别为 12、13、11，产能上限分别为 400、300、500 件。单纯最小化总成本没有意义——订单会集中到成本最低的产线，另外两条近乎闲置，单线风险过大。目标是使三条线的成本尽量接近，即压低最高的那一条。

设第 i 条线的产量为 xᵢ，成本为 cᵢxᵢ。题目要求即为三条线中成本最高者尽可能低：

$$ \min \quad \max \left\{ 12x_1, \; 13x_2, \; 11x_3 \right\} \quad \text{s.t.} \quad x_1 + x_2 + x_3 = 1000 $$

形式与例一相同，目标中含一个 max。沿用例一的思路，令 z 表示峰值，使每条线的成本都不超过 z，并最小化 z：

$$ \min \quad z \quad \text{s.t.} \quad 12x_1 \leq z, \quad 13x_2 \leq z, \quad 11x_3 \leq z, \quad x_1 + x_2 + x_3 = 1000, \quad 0 \leq x_1 \leq 400, \; 0 \leq x_2 \leq 300, \; 0 \leq x_3 \leq 500 $$

此处 z 的作用与例一相同：约束只保证 z 不低于三条成本，压低 z 的是目标函数，两者缺一不可——只写约束，z 可以任意大；只写目标，z 与三条成本没有联系。

```matlab
% min z
% s.t. 12x1 - z <= 0, 13x2 - z <= 0, 11x3 - z <= 0
%       x1 + x2 + x3 = 1000
f = [0; 0; 0; 1];　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　% 变量 [x1; x2; x3; z]，目标是 z

A = [12,  0,  0, -1;                                         % 12x1 <= z
      0, 13,  0, -1;                                         % 13x2 <= z
      0,  0, 11, -1];                                        % 11x3 <= z
b = [0; 0; 0];

Aeq = [1, 1, 1, 0];                                          % 总产量 = 1000
beq = 1000;

lb = [0; 0; 0; -Inf];
ub = [400; 300; 500; Inf];                                   % 产线上限只压产量

[x, fval] = linprog(f, A, b, Aeq, beq, lb, ub);
fprintf('x = [%.2f, %.2f, %.2f], z = %.2f\n', x(1), x(2), x(3), fval);
```

结果为 `x = [334.78, 300.00, 365.22]`、`z = 4017.39`：三条线成本分别为 4017.39、3900.00、4017.39。第二条线达到 300 件上限而成本最低，因为其单价最高，多分一件就会抬高 z；第一、三条线互相牵制，任一条减少一件，另一条立即补上并超过该值。这是「两段同时取峰值」在三条线上的情形。

这里有两处易错点。第一，产能上限只能加在产量 xᵢ 上。若把 400 写成对成本的约束 `12x_1 ≤ 400`，等价于把产量上限削成 33.33 件，与题目给出的 400 件相差一个数量级；若写成 `z ≤ 400`，则是把峰值误当作产量，两者都使模型与题意不符。第二，z 必须是自由变量，若未将其下界设为负无穷，求解器默认 z ≥ 0；本题最优 z 恰为正，结果看似正确，换成成本可能为负的题目就会给出错误答案。

## 分段计价的运输问题

第三类改写处理价格随销量变化的问题。设某产品的**总库存为 1200 件**，分配到两个市场销售。第一个市场在 500 件之后降价，两个市场的售价、销量上限与成本如下表：

| 项目 | 市场 1 | 市场 2 |
| --- | --- | --- |
| 售价（元/件） | 前 500 件 30，超出部分 20 | 全部 32 |
| 销量上限（件） | 1000 | 800 |
| 单位成本（元/件） | 12 | 15 |

将利润直接写成 `30x₁ + 20(x₁ - 500)` 是错误的：当 `x₁ < 500` 时该项会算出负数，凭空扣减利润。分段计价必须用两个变量分别表示正常价段与降价段的销量：

$$ x_1 = s_1 + s_2, \quad 0 \leq s_1 \leq 500, \quad 0 \leq s_2 \leq 500 $$

其中 s₁ 走正常价，s₂ 走降价后的价。目标函数变为

$$ \max \quad Z = (30 - 12)s_1 + (20 - 12)s_2 + (32 - 15)x_2 $$

约束为两个市场共用这 1200 件库存，且各自不超过自己的上限。式中的 1200 即总库存，并非由两个上限相加得来——左端计入全部货量（市场 1 的 s₁、s₂ 与市场 2 的 x₂），其总和不能超过现有库存：

$$ s_1 + s_2 + x_2 \leq 1200, \quad s_1 + s_2 \leq 1000, \quad x_2 \leq 800 $$

这里还有一个隐含要求：**降价段的单价必须低于正常段**。否则求解器会先填满 s₂ 再填 s₁，等价于低价段优先，与真实定价规则相反。单价较高的分段必须排在靠前的变量中；分段顺序本身就是一项约束。

```matlab
% 变量 [s1; s2; x2]
f = [-(30-12); -(20-12); -(32-15)];　　　　　　　　　　　　　　　　　　　　　　　　　　% 最大化取负
A = [1, 1, 1;　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　% 总库存
     1, 1, 0];　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　% 市场 1 销量上限
b = [1200; 1000];
lb = [0; 0; 0];
ub = [500; 500; 800];

[s, fval] = linprog(f, A, b, [], [], lb, ub);
Z = -fval;
fprintf('s1 = %.0f, s2 = %.0f, x2 = %.0f, Z = %.0f\n', ...
        s(1), s(2), s(3), Z);

    % s1 = 500, s2 = 0, x2 = 700, Z = 20900
```

求得 `s1 = 500`、`s2 = 0`、`x2 = 700`，最大利润 20900 元。市场 1 的降价段未分配任何销量：市场 1 降价后的单位毛利为 8 元，低于市场 2 的 17 元，在库存有限时，货量应优先分配给单位毛利更高的市场。该结论可直接从模型读出，无需额外推导。

进一步看：市场 1 的销量上限为 1000 件，实际只售出 500 件，其余 500 件额度空置。空置并非浪费，而是模型在比较同为 500 件的两种用途：投入市场 1 的降价段每件贡献 8 元，投入市场 2 每件贡献 17 元，因此全部分配给市场 2。「市场 1 只卖 500 件」看似保守，实为最优。

## 小结

这一课处理的都是「表面上不能用线性规划」的问题，改写手法归纳为一种：引入新变量，把求解器不能直接处理的部分替换为线性形式。

- **绝对值在目标函数**：引入 `u_i ≥ |x - a_i|` 并求最小，uᵢ 会被压到下界；求最大时不成立；
- **绝对值在约束里且要求「不超过」**：直接拆成两条不等式；要求「不小于」时可行域不连通，不能用线性规划表达；
- **最小化最大值**：引入公共上界 z，写成 `c_i^T x ≤ z`，把 z 压小；
- **分段计价**：每段一个变量，各段上下界独立，且段内单价必须按从高到低顺序排列，否则求解器会先填低价段。需要整数时换成整数规划，换用 `intlinprog` 或 `@GIN()`；

这些改写的共同点是**只改表述，不改问题**。改写后仍需回答上一课提出的三个问题：求解器返回的状态是什么，结果能否代回原题验证，模型中每一条约束是否都有现实含义。最后一问尤为重要——改写引入了题目中原先不存在的变量，若不能逐条说明其含义，模型尚未完成。

下一课转向另一个问题：不再假设系数确定，而是考察原料库存减少、售价下降时，最优解是否仍然成立。
